# CAROVAL — Pasta dari Ampas Wortel

Website presentasi/interaktif untuk produk NASPO CAROVAL.

## Struktur
- `index.html` — halaman utama
- `style.css` — desain/responsive
- `script.js` — interaksi produk + mini quiz
- `assets/mascot-caroval.png` — maskot CAROVAL

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload SEMUA isi folder ini.
3. Pastikan `index.html` berada di bagian paling luar repository.
4. Buka **Settings → Pages**.
5. Pada Source pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`.
7. Save, lalu tunggu GitHub Pages membuat link website.

Tidak membutuhkan database atau server.
